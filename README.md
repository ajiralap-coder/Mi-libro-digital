# Todo lo que todavía no sé decirte — guía rápida

## Cómo abrirlo
1. Descomprimí `libro_agustina_web.zip`.
2. Abrí la carpeta `libro_agustina_web` en Visual Studio Code.
3. Abrí `index.html` en tu navegador. Si tenés la extensión **Live Server**, podés hacer clic derecho sobre `index.html` y elegir **Open with Live Server**.

## Qué incluye
- El manuscrito integrado desde el archivo de texto, respetando la redacción y el orden de los apartados.
- Distribución en páginas cortas para que la lectura sea más cómoda en celular y computadora.
- Portada, índice navegable, animación de paso de página y barra de progreso.
- Navegación con botones, flechas del teclado y gesto de deslizar en celular.
- Sonido de hoja opcional (apagado por defecto).
- Diseño adaptable y soporte para la preferencia de reducir animaciones.

## Archivos
- `index.html`: estructura y portada del sitio.
- `styles.css`: colores, tipografías, márgenes y animaciones.
- `script.js`: contenido del libro y lógica de navegación.

## Nota sobre el texto
El contenido se integró a partir del `.txt` que compartiste. Se mantuvieron las palabras y el orden de los apartados; algunos párrafos largos se separaron en bloques más breves en los puntos de corte entre oraciones para que entren mejor en las páginas. Revisá la vista en tu navegador antes de publicar, porque el tamaño puede variar según la pantalla.

Las tipografías web requieren conexión a internet; sin conexión, se usarán tipografías de reserva.
